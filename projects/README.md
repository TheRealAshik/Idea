# 🚀 Projects

This directory holds scoped, multi-stage project plans, blueprints, and architecture designs ready for execution or currently under active development.

## Folder Guidelines
- Store project specifications as individual Markdown files or dedicated subdirectories (for larger projects).
- Keep project statuses up to date (`Planning`, `In Progress`, `Shipped`, `On Hold`).
- Use `templates/idea-template.md` as the baseline structure when drafting new projects.
